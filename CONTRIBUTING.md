# Contributing to Fraktal

Read [AGENTS.md](AGENTS.md) for the architecture, source ownership and required
engineering gates, and read the relevant specification before changing behavior.

Unless a separately identified component's existing license applies, contributions
intentionally submitted for inclusion in Fraktal are offered under
**AGPL-3.0-only**, the current project license. Include an appropriate copyright
notice for substantial new work; preserve existing notices. For a new standalone
source file, use `SPDX-License-Identifier: AGPL-3.0-only` in its language's normal
comment syntax where appropriate. Do not edit serialized PLC object graphs
merely to add a header.

Submit only work you have authority to license this way, including any required
employer authorization. Identify third-party code, its origin and its license;
do not replace its notices with Fraktal's. A contribution does not assign your
copyright or grant a separate proprietary relicensing right.

Commits should state the change, its purpose and the applicable validation.
Controller-changing actions still require current authorization and exact target
checks. Evidence remains append-only. See [LICENSING.md](LICENSING.md) for
historical MIT permissions and distribution obligations.
