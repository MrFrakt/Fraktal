## CPU 1214C DC/DC/DC `6ES7214-1AG40-0XB0`, FW V4.7 [sheet, 2026-09-28]

- Work memory **150 KB** (program + data), load memory 4 MB, retentive **14 KB**, bit memory 8 KB.
- Local data: 16 KB for OB1 (priority class 1), 6 KB for classes 2–26.
- Processing: bit 0.08 µs, word 1.7 µs, floating point 2.3 µs per instruction (typ.).
- PROFINET IO controller: 16 devices, RT only (no IRT, no MRP). OUC TCP/ISO-on-TCP 8 KB per job.
- Connections: PG 4/4, HMI 12/18, S7 8/14, open user 8/14, web 2/30, OPC UA 0/10, total 34/68.
- Security: PG/OP over TLS 1.3 pre-selected; user management 42 users / 14 groups / 20 roles;
  protection levels write / read-write / complete.
- Traces: 2 × 512 KB. Web server with user pages. LAD/FBD/SCL only.
