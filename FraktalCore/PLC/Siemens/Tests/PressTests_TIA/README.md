# Wired GRAPH press checks

`probe_live.py` operates the generated press through its authenticated Web API
mailbox on an isolated CPU1516. It checks private owner storage, the static
engineering register, HOME single-step/hold-to-run, the CHANGEOVER decision
JUMP1 from880 back to810, repeated confirmation, answers retained behind pacing,
and lifecycle host events. ST/LD twins remain unwired examples.

The fixed `bench.json` names `FrkPressFeaturesTest`, unmapped
`169.254.212.56` / `172.31.254.56`. `run_live.py` requires a clean native compile
and canonical read-back witness before downloading its saved isolated project.
Use `Tests/Access/with_credentials.ps1` to supply the existing DPAPI credential;
plaintext passwords never appear in plans or evidence.

Web-user preparation happens on the offline project before hosting, followed
by one download. Two consecutive full downloads on the same fresh test CPU
caused a large temporary simulator allocation on this VM; closing that test
instance recovered the space without deleting projects or storage. The shared
session helper always signals the stop file and waits for host exit.

The saved `Fraktal` runtime and physical1214C are preserved. These tests prove
software sequence behavior in the simulated plant; bench wiring, certified
safety behavior and physical press acceptance remain commissioning work.
